# README
This folder contains all the nesessary MATLAB code needed to fun the five underwater acoustic test cases:
1. Tiawan Sea
2. Korean Sea
3. NESMA 3D
4. NESMA 2D
5. Double Seamount

## Instructions
Extract the AcousticToolBox.zip file and add it and all subfolders to your MATLAB path.

## Notes
The other zip file, OriginalATwithTests.zip, contains all the original files from Mike Porter's Acoustic Toolbox.
