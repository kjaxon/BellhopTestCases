# README

This folder contains some MATLAB files for plotting the New England Seamount in 3D. The two main files you will interface with are NESMA_Eigen and NESMA_TLoss. Make sure to add the AcousticToolkit and bellhopcuda files to the MATLAB path so the files run correctly.

write_bty3d, plot-tl-slice, and plotbathy3d are helper functions. Each are commented with detailed descriptions.

NESMA_LatLongMapping is a seperate file that creates a top down map of the New England Seamount. This is useful when changing the cropped area for the bathymetry and determining the source and reciever locations.
